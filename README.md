
# APEX Corporate KPI Tracking and Staff Appraisal

  This is a code bundle for APEX Corporate Training UI. The original project is available at https://www.figma.com/design/fJPLnlRfCtLJb2tLC6A0u8/APEX-Corporate-Training-UI.

## Live deployment

[Open the APEX KPI & Staff Appraisal prototype](https://apex-kpi-staff-appraisal.vercel.app)

The production site is hosted on Vercel. Updates pushed to the `main` branch are automatically built and deployed.

## Run locally

1. Install Node.js 18 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:5173` in your browser.

## Prototype accounts

All sample accounts use the password `demo1234`.

| Account | Email | Organisational role |
| --- | --- | --- |
| Employee A | `employee@apex.test` | Employee |
| Manager A | `manager@apex.test` | Manager / HOD |
| Trainer A | `trainer@apex.test` | Trainer |
| HR A | `hr@apex.test` | HR |
| Super Admin | `admin@apex.test` | Super Admin |

Manager / HOD and HR accounts retain employee self-service access, including My KPI Plan and My Assessments. Navigation and direct route access are both controlled by the signed-in account.
